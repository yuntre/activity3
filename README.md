# Mini Student Portal

This project was uploaded for activity purposes only.

This repository is intended for activity use only and is not meant to be distributed as a completed or production-ready application.

## How to run

1. Open the project folder in VS Code.
2. Open a terminal in the project directory.
3. Run: `npm install`
4. Then run: `npm run dev`
5. Open the local URL shown in the terminal, usually http://localhost:5173

To stop the app, press `Ctrl + C` in the terminal.
